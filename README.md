# Enterprise Supply Chain Intelligence & Inventory Optimization System (SQL + Analytics)

## 📌 Project Overview

This project simulates a real-world enterprise supply chain analytics system designed to optimize inventory management, reduce stockouts, and improve warehouse efficiency using SQL-based analytics.

The system analyzes multi-dimensional data across products, orders, customers, and warehouses to generate actionable business insights for operational decision-making.

---

## 🎯 Business Problem

Modern retail supply chains face challenges such as:

* Frequent stockouts of high-demand products
* Overstocking of slow-moving inventory
* Inefficient warehouse distribution
* Lack of visibility into product performance
* Revenue loss due to supply-demand mismatch

This project solves these problems using structured SQL analytics.

---

## 🧠 Key Objectives

* Identify inventory inefficiencies and stockout risks
* Analyze product demand patterns and revenue contribution
* Evaluate warehouse performance across regions
* Segment customers using RFM analysis
* Classify products using ABC analysis
* Detect revenue leakage due to supply chain inefficiencies

---

## 🛠️ Tech Stack

* SQL (PostgreSQL)
* Window Functions
* CTEs
* Joins & Subqueries
* Data Modeling Concepts

---

## 📊 Key Business Insights Delivered

* Inventory turnover and demand trends
* High-risk stockout products
* Top-performing warehouses
* Customer segmentation (High / Mid / Low value)
* ABC classification of products
* Revenue contribution analysis

---

## 📌 Outcome

This project demonstrates end-to-end data analytics capability in a real-world supply chain environment, similar to analytics roles in retail, logistics, and e-commerce companies.
